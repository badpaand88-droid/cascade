КАСКАД НА IPHONE / IPAD

На iPhone устанавливается официальный клиент sing-box из App Store. Этот раздел не содержит отдельного IPA или приложения Cascade для настройки серверов.

1. Откройте https://sing-box.sagernet.org/clients/apple/ и перейдите по официальной ссылке App Store. На дату подготовки ссылка ведёт на sing-box MT:
   https://apps.apple.com/us/app/sing-box-mt/id6785326793
   Если приложение недоступно в регионе аккаунта, проверьте доступность у разработчика; неподписанный IPA в комплект не входит.

2. Получите профиль для своего устройства в Cascade на Mac или Windows:
   - Введите доступы двух VPS и проверьте SSH каждого.
   - Для существующего каскада нажмите «Получить конфиги».
   - Для нового сначала выполните подготовку и установку.
   - Создайте отдельный профиль с именем «iPhone».
   - Сохраните BPF или JSON. На Mac можно сохранить JSON; при импорте в SFM также создаётся BPF. Windows-версия имеет отдельную кнопку экспорта BPF.

3. Передайте файл на iPhone через AirDrop (с Mac) или своё приложение «Файлы». Файл содержит ключ доступа: не публикуйте его и не помещайте в открытые ссылки.

4. Импорт BPF:
   Откройте файл .bpf и выберите sing-box в меню «Поделиться» / «Открыть в». Подтвердите импорт, если клиент показывает запрос.
   Импорт JSON:
   В sing-box откройте добавление профиля, выберите локальный профиль и импорт из файла, укажите .json. Названия пунктов могут отличаться между версиями.

5. Выберите профиль и включите VPN. Подтвердите системный запрос iOS на добавление VPN-конфигурации. Не отключайте проверку сертификатов.

6. Проверка:
   Откройте https://api.ipify.org в Safari. Должен отображаться IP выходного VPS (либо его NAT-адрес). Проверьте нужные сайты. Повторите на Wi-Fi и мобильной сети отдельно.

QR:
- «QR установки из App Store» — только ссылка для установки клиента, не VPN-профиль.
- Cascade выдаёт VLESS-QR и JSON-QR. Их сканирование поддерживают не все клиенты; для официального sing-box используйте BPF или JSON-файл.

Ваши реальные профили в эту папку автоматически не копировались. Создайте их в Cascade: это не позволяет случайно раздать один ключ всем получателям комплекта.

Установка SFI/MT и импорт профиля на физическом iPhone для этого комплекта не проверялись.
