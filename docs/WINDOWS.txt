CASCADE ДЛЯ WINDOWS · 0.3.0 · x64

ТРЕБОВАНИЯ
Windows 10/11 x64, интернет, два VPS с Ubuntu 22.04/24.04/26.04 либо Debian 12/13, root или sudo без пароля. TCP 443 должен быть свободен на обоих VPS. Внешний firewall панели хостинга настраивается отдельно.

УСТАНОВКА
1. Запустите Cascade-Setup-x64.exe.
2. Нажмите «Установить Cascade». Программа установится для текущего пользователя в:
   %LocalAppData%\Programs\Cascade
   .NET включён; отдельно устанавливать SDK или runtime не нужно.
3. В меню «Пуск» появится Cascade. При выбранном флажке появится и ярлык рабочего стола.
4. Нажмите «Запустить Cascade».

Сборка пока не подписана коммерческим сертификатом Windows. Издатель не будет подтверждён такой подписью; системные проверки безопасности не отключались. Для обычного публичного распространения требуется отдельная подпись и проверка установщика на Windows.

НАСТРОЙКА НОВОГО КАСКАДА
1. Введите IP, SSH-порт и логин каждого VPS, пароль либо приватный SSH-ключ и его пароль.
2. Проверьте подключение каждого сервера. При первом соединении сверьте SSH-отпечаток с консолью/панелью хостинга.
3. После двух проверок повторно подтверждать отпечатки не нужно. Можно проверить TCP-связь и TLS-сайт.
4. Нажмите «Подготовить установку», затем «Установить каскад».
5. Установщик создаст отдельные сервисы bp-cascade; схема:
   компьютер → входной VPS → выходной VPS → интернет.
   На обоих участках VLESS + REALITY + Vision. Собственный домен не нужен.
6. Дождитесь сквозного теста и выберите профиль устройства.

УЖЕ УСТАНОВЛЕННЫЙ КАСКАД
После двух успешных SSH-проверок нажмите «Получить конфиги». Повторная установка не нужна. Требуется тот же TLS-сайт, что был указан при первоначальной установке.

ПОДКЛЮЧЕНИЕ WINDOWS К VPN
1. Кнопка «Установить sing-box для Windows» скачает официальный SFW 1.14.4 из GitHub Releases и проверит SHA-256.
2. Подтвердите открытие официального установщика и завершите его системные шаги. Не заменяйте уже работающий клиент без необходимости.
3. Сохраните JSON выбранного устройства. В клиенте sing-box добавьте локальный профиль и импортируйте JSON-файл; затем включите его. Системе могут потребоваться права администратора для VPN/TUN.
4. Проверьте внешний IP на https://api.ipify.org — он должен соответствовать выходному VPS.

ПРОФИЛИ И IPHONE
Для каждого устройства укажите отдельное имя и нажмите «Создать профиль». Устройство получит собственный UUID; старые ключи сохраняются. Во время добавления входной сервис кратко перезапускается, соединения могут прерваться. Дождитесь подтверждения.
JSON — для клиента sing-box; BPF — переносимый профиль для совместимого SFI/SFM; QR — VLESS-ссылка или полный JSON. Поддержка сканирования зависит от клиента. Для iPhone следуйте инструкции в разделе iOS.

ОТКАТ И УДАЛЕНИЕ
«Откатить…» восстанавливает серверную настройку операции текущего сеанса. Если связь пропала, приложение сообщает, что восстановление не подтверждено: повторите проверку SSH и откат, не запускайте установку вслепую.
Удаление самого Cascade: «Параметры Windows → Приложения → Cascade → Удалить». Экспортированные профили, данные кэша и настройки VPS удалением программы не затрагиваются. Для удаления VPS-сервисов используйте подтверждённый откат либо отдельное администрирование.

КОНФИДЕНЦИАЛЬНОСТЬ
SSH-доступы находятся в памяти; при закрытии приложения их нужно ввести заново. Не отправляйте разработчику пароли и приватные SSH-ключи. JSON/BPF/QR содержат ключ доступа к VPN. Не публикуйте их. Техническая проверка обращается к GitHub, выбранному TLS-сайту, api.ipify.org и www.cloudflare.com; телеметрии и регистрации нет.

ГРАНИЦЫ ПРОВЕРКИ
EXE собран на Mac для Windows x64. Криптография, генерация конфигов, BPF, QR и общие сценарии проверяются отдельно; фактический запуск GUI, системная установка/удаление и подключение SFW на настоящей Windows для этой сборки не проверены. Сначала используйте тестовый ПК и чистые тестовые VPS. Текущий рабочий VPN устанавливать заново не требуется.
