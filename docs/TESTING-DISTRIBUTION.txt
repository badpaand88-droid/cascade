КАСКАД · КОМПЛЕКТ 0.3.0 · 12 НОЯБРЯ 2026

WINDOWS
Собраны два настоящих Windows x64 GUI PE:
- Cascade.exe — автономное приложение, .NET включён.
- Cascade-Setup.exe — автономный установщик со встроенным ZIP приложения.

Пройдены 7 проверок Windows-логики на macOS:
1. Валидация адресов/портов/SSH-логина и защита от подстановки команд.
2. X25519, отдельные UUID и сохранение старых пользователей/маршрутов.
3. Генерация BPF и обоих QR без серверных приватных ключей.
4. Нельзя обойти SSH-проверки или указать одинаковые VPS.
5. Общие серверные шаблоны подставлены полностью и приняты bash -n.
6. Все конфиги приняты официальным sing-box 1.14.4.
7. Реальный локальный каскад из двух REALITY-узлов с .NET-ключами работает; остановка выхода разрывает запрос без прямого обхода.

Дополнительно:
- Apple Vision распознал VLESS-QR и JSON-QR с совпадением содержимого.
- Независимый Python/gzip-декодер прочитал BPF; JSON совпал с исходным.
- Проверены архитектура и GUI-подсистема обоих PE, SHA-256 встроенного ZIP, безопасные пути и отсутствие пользовательских конфигов/QR в установщике.

На настоящей Windows пока НЕ проверены: запуск GUI, установка, обновление, удаление, работа SFW/TUN и SSH к реальным VPS именно из этой версии. Сначала требуется проверка на тестовом ПК. Windows App на Mac — клиент удалённого доступа, а не тестовая Windows-система.

MACOS
Включена ранее собранная Cascade 0.3.0 для Apple Silicon, macOS 14+. Для Mac-версии ранее прошли 28 тестов. Каскад версии 0.2.1 пользователь установил на реальных VPS; активный SFM, входной узел и внешний IP выходного узла были подтверждены. Новые операции добавления устройств проверены на стенде.

IOS
Включены инструкция, официальные ссылки и QR установки клиента из App Store. Отдельный IPA Cascade не создавался. Импорт на физический iPhone в рамках этого комплекта не проверен. Индивидуальные VPN-профили нужно сформировать в Cascade — реальные ключи в общий комплект не включены.

ПОДПИСЬ
Windows EXE не имеет Authenticode-сертификата. Mac-приложение имеет ad-hoc подпись, без нотариализации Apple. Проверки безопасности ОС не отключались.
