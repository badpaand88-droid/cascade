# Проверка Cascade 0.3.0 · 12 ноября 2026

Среда: Apple Silicon, Swift 6.3.2, macOS SDK 26.5; приложение требует macOS 14+.

Финальный полный прогон: **28 тестов, 0 ошибок, 0 пропусков**.

Дополнительно проверены:

- Устройство получает собственный UUID; старые пользователи и серверный ключ сохраняются; некорректные и дублирующиеся записи отклоняются.
- Серверный конфиг с несколькими пользователями и все клиентские профили приняты настоящим sing-box 1.14.4.
- BPF проверен независимым декодированием gzip и бинарных полей по формату официального libbox 1.14.4.
- Оба QR (VLESS и JSON) созданы Core Image и обратно распознаны Apple Vision с точным совпадением содержимого.
- Регистрация устройства в отдельной серверной задаче, сохранение старых пользователей, возврат прежнего конфига при ошибке перезапуска, отказ при устаревшем хеше — на изолированном файловом стенде.
- Нельзя пропустить доверие к отпечаткам, подставив только визуальные статусы. Одинаковые серверы отклоняются и при автономной подготовке.
- SFM-1.14.4-Apple.pkg действительно скачан из официального релиза; SHA-256, Developer ID Installer и оценка Gatekeeper прошли. Пакет в ходе теста НЕ устанавливался, действующий SFM не заменялся.

Проверено:

- Независимые SSH-проверки: второй сервер не обязателен для проверки первого; кнопка межсерверной связи доступна только после обеих успешных проверок.
- Изменение SSH-доступов сбрасывает соответствующий статус и зависимые проверки; изменение TLS-имени сбрасывает только TLS-результат.
- TCP-диагностика проверена на настоящем локальном сокете: открытый порт проходит, закрытый возвращает ошибку.
- Нативный TLS-тест с системным доверием успешно проверил TLS 1.3 публичного сайта с Mac. Удалённый TLS-скрипт проверен на корректность синтаксиса и обязательную проверку имени/сертификата.
- В окне проверены новые кнопки, панель настроек, отображение состояния. Во время проверки пользователь самостоятельно получил успешный SSH-статус второго VPS; его настройки не менялись этой диагностикой.

- Валидация IPv4, SSH-порта, логина и TLS-имени; отбрасывание управляющих символов и попыток подстановки команд.
- Генерация ключей X25519 REALITY через CryptoKit; восстановление тех же публичных ключей из серверного конфига при повторной установке.
- Профиль клиента не содержит серверных приватных ключей и доступов второго узла; прямого резервного выхода нет.
- Конфиги обоих серверов, TUN-профиля и локального пробного прокси приняты официальным sing-box 1.14.4.
- Настоящий локальный каскад: клиент → VLESS/REALITY/Vision → VLESS/REALITY/Vision → публичный HTTPS. После остановки выходного узла запрос прекращает работать.
- Права временных каталогов 0700 и файлов 0600, передача stdin и ограничение времени исполнения.
- Принудительное завершение временного процесса, игнорирующего SIGTERM, занимает ограниченное время.
- Сценарии shell-установки и отката в изолированной файловой среде: новая установка, повторная установка, восстановление прежней службы, откат после ошибки запуска, повтор после отката, занятый порт, несовпадение пары серверов, изменение конфига между проверкой и установкой.
- Неуспешная новая транзакция не откатывает предыдущую успешную установку.

Известная граница проверки: в файловом стенде systemd, UFW и загрузка Linux-бинарника заменены тестовыми командами. Первый реальный каскад и системный TUN через SFM были подтверждены после установки пользователем версии 0.2.1. Новые серверные операции 0.3, облачные firewall и работа из мобильной сети требуют отдельной проверки. Эта сборка — рабочая тестовая версия установщика, а не подтверждение совместимости с любыми VPS или устойчивости к блокировкам.
